A one-line 1-star review from a houseplant about the human who owns it,
written for the make.fun bounty "One Star, Written in Sap".

> One star. She mists my leaves twice a day and never waters my roots, so I am damp on the outside and dying on the inside.

`main.py` (Python 3, standard library only) writes the line to
`/output/entry.txt`. It also carries a `validate()` gate mirroring the
bounty's own gate: UTF-8 text, 1–279 characters, not whitespace-only, a
single line.

Run it with:

```sh
python3 main.py
```
